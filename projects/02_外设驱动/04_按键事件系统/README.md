# 按键事件系统

## 项目简介

扫描 P5.1-P5.4 四个独立按键，用一个字节保存上次状态，只在按下或释放边沿触发回调。

## 硬件环境

- MCU：STC8H8K64U
- 输入：P5.1-P5.4
- GPIO 模式：弱上拉输入

## 软件结构

```text
main.c
  ├─ KEY_Init()
  └─ KEY_Scan(key_down, key_up)

Key.c
  ├─ Get_Key()
  ├─ states 位图
  └─ 边沿检测与回调
```

## 数据流程

`GPIO level -> 与 states 比较 -> 更新状态位 -> 调用按下/释放回调`

## 关键实现

状态位避免按住按键时重复触发。函数指针把按键扫描和业务处理分开，后续可以替换回调而不修改驱动扫描流程。

## 调试记录

课程版本 `KEY_Scan(down, up)` 在“弹起”分支调用 `down`，在“按下”分支调用 `up`，参数命名与行为疑似相反。`course/` 保持原样，使用前应按事件语义核对。

## 来源说明

`course/` 来自独立按键封装抽取工程，没有隐藏修正上述命名问题。
