# 调试记录

## OLED 代码整合

集成同类驱动时需要重点避免三类符号冲突：

- `delay_ms` 在 OLED 源码和公共 `Delay.c` 中重复定义。
- `REG51.h` 与 `STC8H.h` 重复定义 P0 等寄存器。
- `u8/u16/u32` 在 OLED 头文件和 `Type_def.h` 中重复定义。

处理重点不是删除任意文件，而是明确每个符号只由一个公共头文件或源文件提供。

## Keil Include Path

多目录工程出现 `can't open file` 时，应先核对 Keil C51 的 Include Paths，而不是复制多个同名头文件到工程根目录。

## UART 与 USB 模式

P3.0/P3.1 同时涉及 CH340N 串口和 USB D-/D+ 路径。串口无输出、HID 无法枚举或下载失败时，先检查板载切换开关和当前工程使用的引脚组。

## RTC 启动时间

持续走时的应用应把首次初始化与周期读取分开，避免每次启动覆盖 RTC。

## 实现检查点

- 按键扫描接口需要同时核对调用参数、事件分支和去抖策略。
- EEPROM/IAP 数据路径需要验证擦除、写入、读回和掉电后的持久性。
- 板端结果以实际硬件记录为准；文件存在或历史构建产物不能替代当前验证。
