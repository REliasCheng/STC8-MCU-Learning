# 工程结构演进

## 1. 直接控制

最初的 LED 工程在 `main.c` 中配置 GPIO 并直接改变端口电平，重点是 PnM0/PnM1 与端口输出。

## 2. 厂商库

GPIO、UART、Timer、PWM、ADC 等工程逐步使用 STC 外设库。`Config.h` 统一主频，`Switch.h` 管理外设引脚映射。

## 3. 模块封装

按键、数码管、RTC、DHT11 等功能拆分为独立 `.c/.h`：

```text
main.c
  ├─ 初始化模块
  ├─ 调用接口
  └─ 处理应用流程

driver.c / driver.h
  ├─ 配置端口或外设
  ├─ 执行协议时序
  └─ 返回状态或数据
```

## 4. 回调和状态

按键模块使用状态位保存上一次扫描结果，通过函数指针上报按下和释放事件。矩阵键盘把 4×4 状态压缩到 16-bit 位图，再映射为 HID 报告。

## 5. 中断与缓冲

UART ISR 负责收集字节，主循环或周期任务等待接收超时后处理缓冲区。Timer0 工程用 1 ms 中断调用 `Handle_Timer0_Interrupt()`，把中断入口和业务处理分开。

## 6. 多外设与任务

RTC + OLED 工程同时使用硬件 I²C 和软件 I²C。RTX51 Tiny 工程进一步使用 task、tick 等待和 signal，在 UART 事件与 LED 任务之间传递状态。
