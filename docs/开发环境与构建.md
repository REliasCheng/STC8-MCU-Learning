# 开发环境与构建

当前默认分支包含可移植核心、Host Test 和 STC8H8K64U UART1 C51 适配源码，但不包含可复现的 Keil 目标工程、启动文件或 HEX 构建证据。以下内容说明未来建立目标工程时的工具链边界。

## 工具

- Keil C51 / µVision：打开和构建 `.uvproj` 工程。
- STC-ISP：选择 STC8H8K64U、IRC 频率和串口，下载 HEX。
- 串口终端：查看 UART 输出或发送控制命令。

## 工程配置

主频、UART 波特率发生器和引脚映射必须按新建工程的目标芯片、实际晶振与板级连接确定，不能从文档默认值推断。

RTX51 Tiny 工程使用 `_task_` 入口，不再定义传统 `main()`。若出现 `MULTIPLE PUBLIC DEFINITIONS: MAIN`，应检查是否同时保留了普通入口和 RTX51 启动入口。

## 构建步骤

1. 从授权渠道取得 Keil C51 与 STC8H8K64U 器件支持，并新建工程。
2. 将仓库的 `include/` 与 `platform/stc8/` 加入 Include Paths；`STC8H.H` 由本地合法工具链提供，不复制进仓库。
3. 加入 `src/core/ring_buffer.c`、`platform/stc8/stc8_uart.c` 与 `platform/stc8/stc8_uart_c51.c`。
4. 明确系统时钟、UART1 波特率和实际板级引脚路由，再调用初始化、挂载和启动接口。
5. 构建并记录编译器版本、warning/error、CODE/DATA size 与 HEX 输出。当前仓库没有提供这一目标构建证据。

## 下载注意

UART 与 USB HID 共用 P3.0/P3.1 相关路径。串口下载、串口调试和 USB HID 运行前，应确认板载模式开关处于对应位置。
