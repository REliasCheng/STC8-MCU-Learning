# 核心板与引脚复用

当前默认分支不分发核心板原理图。以下内容是资源规划检查清单；具体连接必须以实际板卡原理图、丝印和目标芯片手册为准。

## 板载资源

| 资源 | 集成时需要确认 |
| --- | --- |
| 板载 LED | GPIO、有效电平和上电默认状态 |
| 板载按键 | GPIO、上下拉、电气去抖和外部中断占用 |
| 调试 UART | RX/TX 引脚、波特率发生器和电平标准 |
| USB | D-/D+ 复用关系、时钟和板载切换电路 |
| 串行存储器 | 总线引脚、地址、供电和上拉电阻 |
| 电源 | 输入电压、稳压能力、地线和外设电流预算 |

## 资源映射方法

- 为每个外设记录 GPIO、alternate function、Timer channel、interrupt 和电源需求。
- 在同一张资源表中检查 UART、I²C、PWM、ADC 与板载功能是否争用引脚。
- 对需要精确定时的传感器和通信接口，记录时钟源与最大阻塞时间。
- 对显示、存储和 RTC，记录总线共享方式、设备地址与复位引脚。

实现固件时不能只复制驱动函数，还要核对引脚组、板载开关、外设占用与实际电气连接。当前文档不构成具体板卡接线证明。
