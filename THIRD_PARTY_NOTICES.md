# Third-Party Notices

## Current Default Branch

The current default branch distributes no course source, STC vendor source, startup files, USB/HID implementation, RTX51 library, external image, font, or binary component.

The SDCC target path contains a repository-authored minimal register declaration, adapter and application. The register addresses and bit positions were checked against STC's published STC8H technical reference; the vendor header itself is not included. SDCC and its runtime/startup are external GPL-licensed build dependencies and are not redistributed here. Generated HEX and build artifacts are not committed.
